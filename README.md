# TDM Shooter

Multiplayer Team Deathmatch shooter for Windows, built in Unreal Engine 5.6.

## Requirements

- Unreal Engine 5.6
- Visual Studio 2022 with the **Game development with C++** workload

## Build and run

1. Right-click `TDMShooter.uproject` and choose **Generate Visual Studio project files**.
2. Open `TDMShooter.sln` and build **Development Editor | Win64**.
3. Open `TDMShooter.uproject`.
4. To test multiplayer, set the **Play** dropdown to **Number of Players: 2** and **Net Mode: Play As Listen Server**, then press **Play**.
